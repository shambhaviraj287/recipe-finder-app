# Recipe Finder Web App

A full-stack web application that suggests recipes based on user-input ingredients. Users can sign up, log in, and save their favorite recipes for later.

🚧 **Status:** In progress — actively being built (Aug–Sept 2026)

## Features

- [ ] Ingredient-based recipe suggestions using a third-party API (Hugging Face)
- [ ] User authentication (JWT-based signup/login)
- [ ] Save and manage favorite recipes per user
- [ ] Responsive React frontend

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Auth:** JWT (JSON Web Tokens)
- **External API:** Hugging Face
